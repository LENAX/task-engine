# Release Note - v1.0.15

**发布日期**: 2026-03-08

## 概述

v1.0.15 主要包含实时 DataCollector 接口与注册方案增强：**采集器注册时机改为 WorkflowBuilder**、runStreamProcessor 支持调用 DataHandler、开发指南与 E2E 示例更新。

---

## 增强 (Enhancements)

### DataCollector 注册改为 WorkflowBuilder

- **WorkflowBuilder.WithDataCollector(name, collector)**：推荐在构建 Workflow 时注册 DataCollector，与 WithRealtimeTask 同处一处，语义更清晰。
- **Workflow** 增加 `GetCollectorRegistry()` / `SetCollectorRegistry()`，Build 时将注册表写入 Workflow；Engine 创建 RealtimeInstanceManager 时**优先使用 Workflow 自带的 DataCollectorRegistry**。
- **兼容**：EngineBuilder.WithDataCollector 仍可使用，当 Workflow 未带注册表时回退使用 Engine 级注册表。

涉及模块：`pkg/core/workflow/workflow.go`、`pkg/core/builder/workflow_builder.go`、`pkg/core/engine/engine.go`、`pkg/core/builder/realtime_task_builder.go`。

### runStreamProcessor 调用 DataHandler

- **DataHandlerRegistry**：realtime 选项增加 WithFunctionRegistry，供 runStreamProcessor 按名获取 Job 函数。
- **runStreamProcessor**：从 DataBuffer Pop 后，若配置了 DataHandler 且已传入 FunctionRegistry，则以 `params["data"]` 调用该 Job 函数，再发布 EventDataProcessed。
- **RealtimeTaskBuilder.WithJobFunction**：会同步设置 ContinuousTaskConfig.DataHandler，便于 StreamProcessor 任务消费缓冲并执行业务逻辑。

涉及模块：`pkg/core/realtime/options.go`、`pkg/core/realtime/realtime_instance_manager.go`、`pkg/core/builder/realtime_task_builder.go`、`pkg/core/engine/engine.go`。

### 文档与 E2E

- **docs/realtime-workflow-guide.md**：按本次 API 更新修订；增加 3.8 完整示例（基于 E2E：有限次 publish、Pull HTTP、Push WebSocket），示例中采集器均在 WorkflowBuilder 处注册。
- **test/e2e/realtime_collector_e2e_test.go**：三个 E2E 用例改为 WithDataCollector 在 WorkflowBuilder；补充 StreamProcessor 任务与 printDataJob，覆盖采集端与消费端打印。
- **test/e2e/stk_mins_mock_server.go**：StkMins Mock 服务（HTTP 分页 + WebSocket 推送），供 Pull/Push E2E 使用。

---

## 升级建议

- 推荐将 DataCollector 注册从 **EngineBuilder.WithDataCollector** 改为 **WorkflowBuilder.WithDataCollector**，与 WithRealtimeTask 同处构建；旧写法仍可用。
- 若使用流处理任务消费缓冲数据，在 StreamProcessor 任务上 **WithJobFunction(handlerName, nil)**，并在 Engine 的 Registry 中注册签名为 `func(ctx *task.TaskContext) error` 的 DataHandler，从 `ctx.Params["data"]` 取单条数据。
