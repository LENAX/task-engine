# Release Note - v1.0.14

**发布日期**: 2026-02-28

## 概述

v1.0.14 主要包含动态子任务的可观测性与回调增强、依赖注册告警清理以及部分代码精简，属于小幅增强与修复版本。

---

## 增强 (Enhancements)

### 动态子任务：日志截断与成功回调

- **日志截断**：为日志内容增加长度截断，避免超长输出影响可读性与存储，便于排查问题时快速定位关键信息。
- **成功回调**：动态子任务完成时执行成功回调，确保历史完成数统计准确，与运行中/待处理任务状态一致。

涉及模块：`pkg/core/executor/executor.go`、`pkg/core/engine/instance_manager_v3.go`。

---

## 修复 (Fixes)

### 移除依赖已存在告警

- 在任务依赖注册逻辑中移除了「依赖已存在」的重复告警，减少正常场景下的冗余日志与误报。

涉及模块：`pkg/core/task/registry.go`。

---

## 其他 (Misc)

- **代码清理**：从 `instance_manager_v3.go` 中移除未使用或冗余代码（约 21 行），保持实现简洁。

---

## 升级建议

- 从 v1.0.13 升级无需变更配置或 API，可直接替换二进制或依赖版本。
- 若依赖「动态子任务完成数」或日志可读性，建议升级到本版本。
